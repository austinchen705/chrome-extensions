觸發未啟動

數值規則：精氣神等數值達到門檻就送指令。關鍵字規則：遊戲輸出區新出現的文字含有關鍵字（不分大小寫）就送指令；不看開始前的舊紀錄，也不看以 > 開頭的指令回聲，冷卻期間出現的不會補送。其他玩家說的話也可能含有關鍵字，請用不容易被別人說出的詞；安全機制沒勾選時，冷卻是唯一的頻率限制。

規則命中後不會馬上送出，會在 0～這個秒數之間隨機等一段時間再送，等待中會顯示倒數。冷卻從實際送出的時間起算。數值規則與關鍵字規則都適用。

安全機制（預設全部關閉，要用再勾選）

目的：避免指令沒效果時一直重複送。全部關閉時，條件持續成立就每隔冷卻時間重送一次，不會自己停（冷卻最少 3 秒）。

同一條規則在區間內最多觸發這麼多次，超過就停用該規則並警報。

例如飲水 ≤ 200 就送 drink，但附近沒有水：連續幾次沒效果就停用並提醒你。

超過只是延後，不停用規則。

每條規則的冷卻（最少 3 秒）與「回復緩衝」在規則裡設定。

按開始時如果門檻已經達成，會立刻命中一次（再依上面的延遲設定送出）；之後要等數值回升到「回復條件」之上才會再次觸發。修改規則後要重新按「開始觸發」才會套用。驗證碼停止、重新整理遊戲頁、按停止，觸發都會一併停止。
新出現「請輸入上面的數字」或「請輸入上方的數字」會立即停止。請先手動完成驗證，再按開始；舊紀錄不會重複觸發。需在 CatWorld Web 分頁使用。重新整理遊戲頁後會自動停止，避免意外持續執行。
