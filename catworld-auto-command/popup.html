固定指令
指令最短（秒）最長（秒）

固定指令：每一項各自計時，到時間就送出。每一項開始時先送一次，之後在自己的秒數範圍內隨機等一段時間再送，彼此不等；要依序送好幾個指令就用 ; 接起來（例如 ps;px）。

隨機指令
指令最短（秒）最長（秒）

隨機指令：先隨機挑一個，等它自己的時間才送出。每個指令被挑中的機率一樣；秒數只決定「挑中它之後要等多久」，到時間才送出，送出後再挑下一個。

輔助功能（預設全部關閉）
勾了遊戲頁面板才會出現對應的列，改了馬上生效：
警報提示音

預設關閉＝原本的行為：每 10 秒響一次、最多 5 分鐘，回到遊戲頁點一下、按鍵或按「開始」就停。開啟後不會自己停，要按遊戲頁面板標題列（或系統通知上）的「確認」才會停，標題也會一直閃。

在線獎勵

預設開啟。打 sc 後看到「在線獎勵： N分鐘後可領取」，就在 N+1 分鐘後自動送出 reward（驗證碼照常自動辨識）；已經在等的時候再打 sc 不會重複排，重新整理遊戲頁會取消。

怪物分級

q = 怪物強度×2 ÷ 目前經驗。q ≤ 1 白（打了沒潛能）；q ≤ 綠上限 綠；q ≤ 黃上限 黃；更高紅。遊戲沒有公開門檻，請對照遊戲裡的顏色調整。

主要武器與裝備比較

用來判斷鑑定後的鑄模與材料是否適合你；未設定時只依等級建議（LV1～2 賣掉、LV3 以上留著）。

地圖怪物蒐集
尚無紀錄

遊戲頁的地圖視窗開著時，走進房間、輸出區印出怪物行（※名稱(ID)），就會記給你所在的房間（只增不減，重新整理遊戲頁也不會丟）：手動走一輪就蒐集得到。複製出來每列一個房間，Tab 分隔：區域代號、區域名稱、房間代號、怪物（名稱(ID)，逗號分隔）。只存在這台瀏覽器的本機。

裝備資料庫（商人 check）

預設 5S。便宜的多半是食物、藥草這類非裝備，check 要錢又沒用；填 0 就全部都 check。只影響「還沒蒐集的」批次，已經有資料、推薦的裝備不受影響。

用「、」、逗號或分號分隔，名稱要和 list 裡一樣。list 裡符合的商品，每個編號各 buy 一次（遊戲的 buy 不能帶數量），一顆按鈕全部送出，最多一次 20 個，不再確認，所以名稱請填準。留空＝不出現購買鈕。

尚無紀錄

在商人面前自己打 check 編號，輸出的裝備資料（類別、傷害／防禦、佩帶經驗、屬性）就會記下來，以名稱為鍵、不分店、後讀的覆蓋舊的；check 要付錢，工具不會代你送。每次記下來，輸出下面會回報一行（記了哪件、資料庫共幾件）；打 list 時，輸出下面會多一塊摘要：這一頁「建議 check」的編號（穿得了、佩帶經驗比現在穿的高；同名裝備的傷害屬性可能不同，所以只看等級，check 之後才用實際數值比），以及還沒蒐集的編號，兩者都有批次 check 按鈕。整個功能要先勾上面的「啟用裝備資料庫」才會作用（預設關閉，沒勾時不記錄、輸出裡也不會多任何東西）；比較好的判斷還要用面板的「讀取目前穿著」讀過穿著。

額外的遊戲網址（臨時）

讓面板也出現在別的網站上，例如 ngrok 的臨時網址。貼上網址按「新增」，Chrome 會問你要不要讓這個 extension 存取那個網站，按「允許」才會生效；用完按「移除」。新增或移除後，要到那個網站的分頁重新整理。只存在這台瀏覽器的本機，不會匯出。

驗證碼樣本收集
尚未送出

每次驗證碼自動辨識結束（通過、送 3 次都沒回應、讀不出數字）就把那張圖的 HTML 與結果送到這個網址，用來補字形庫。安裝時帶入的是作者的收集表；不想分享就清空（清空後不會再帶入），要收進自己的試算表見 README。HTML 可能含圖前幾行的遊戲輸出，例如狀態卡裡的角色名。網址只存在這台瀏覽器的本機，不會匯出。

出現驗證碼（「請輸入上方的數字」或數字圖）會先自動辨識並送出，讀不出數字或送 3 次都沒回應才停止；停了請先手動完成驗證，再按開始。舊紀錄不會重複觸發。需在 CatWorld Web 分頁使用。重新整理遊戲頁後會自動停止，避免意外持續執行。
