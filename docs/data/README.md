# 資料檔

## shop-items.tsv

商人賣的裝備資料，212 件（2026-11-03），Tab 分隔，第一列是標題。由設定頁「裝備資料庫（商人 check）」的「複製」匯出，是作者在商人面前自己打 `check 編號` 蒐集的結果。

| 欄位 | 說明 |
|---|---|
| 名稱 | 商品名稱，和 list 裡一樣（`[大日皇鞭]` 的方括號是遊戲顯示的） |
| 類別 | 例如 `刀類武器`、`手套類防具` |
| 主要數值 | 傷害力（武器）或防禦力（防具）；check 輸出沒有時留空（衣物類、暗器類、部分盔甲） |
| 佩帶經驗 | 佩帶條件的經驗，沒有條件填 0 |
| 屬性 | 附加屬性，用空白分隔；沒有就留空 |

**同名裝備的主要數值與屬性不一定相同**，所以這份資料可靠的是「類別」和「佩帶經驗」；傷害與屬性只是蒐集當下那一次 check 到的值，不要當成標準值。

資料只是備份，extension 目前沒有匯入功能，commit 進來不會自動出現在別人的 extension 裡。
