# 置頂浮窗

- 面板的置頂浮窗（Document Picture-in-Picture）邏輯在 `pip-panel.js`（不碰 `chrome.*`，浮窗 API、宿主節點、儲存、提示都由 `content.js` 注入）。面板是被「**搬**」進浮窗（同一個節點、事件與 shadow DOM 跟著走），不是複製；放回原位靠留在宿主位置的提示條，提示條被頁面刪掉就放回主頁面根節點，**浮窗被關掉時面板一定要回來**（`pagehide` 與收回都走同一個 `restore`，可重複呼叫）。開到一半失敗要關掉半開的浮窗、放回面板、清掉殘留。
- **不得搬遊戲自己的狀態視窗（`#monitor`）**：搬走之後遊戲與我們用 `getElementById` 讀數值的程式都找不到它。要顯示數值就另外顯示一份。
- 面板在浮窗裡時宿主帶 `data-pip` 屬性，面板的樣式用 `:host([data-pip])` 隱藏拖曳與收合（收合過的面板在浮窗裡要展開）；`content.js` 裡所有用 `document` 算主頁面位置的程式（`replace`、`avoidMap`、拖曳開始）都要先確認 `host.ownerDocument === document`，否則會把浮窗座標存成面板位置。收回後要重新排位置。**新增面板內容時要想到它可能在另一個 document 裡**：別用主頁面的 `document` 找面板內的元素，別假設事件會傳到主頁面的 `window`。
- 玩家的互動要同時聽遊戲視窗與浮窗：警報提示（標題閃爍、提示音）靠 `createInteractionHub`（`watch`、`addWindow`、`removeWindow`），浮窗開啟時 `addWindow`、關閉時 `removeWindow`；新增「靠互動停止」的功能要走同一個 hub，不要直接在 `window` 上掛監聽。
- 浮窗大小：沒有記住的大小時預設寬 360、高度以**展開後**的面板為準（量的當下暫時掛上 `data-pip`、量完立刻拿掉，等瀏覽器建立視窗期間主頁面的面板不能先變成浮窗的樣子）；玩家調整過、收回或關閉浮窗時記在 `chrome.storage.local.pipSize`（只記範圍內的數字，壞掉、零、負數、超大都當作沒記過；用的時候再夾在螢幕可用範圍內；拖回開窗時的大小不記；這次存過就不讓晚到的讀取蓋掉）。重新整理或關閉遊戲分頁時瀏覽器直接關浮窗，這一次的大小可能沒存到，這是已知限制。**Chrome 開置頂視窗時會把請求的大小等比縮小（約螢幕面積四分之一），拖拉卻可以更大，開窗後也不能用 `resizeTo` 放大（實測）**，所以判斷「玩家有沒有調整」的基準是視窗開起來之後的**實際大小**（量不到才退回請求的大小），不能用請求的大小，否則瀏覽器自己縮的會被當成玩家調整、蓋掉玩家記的大小。開窗必須在使用者點擊之後馬上呼叫，所以大小在建立控制器時就先讀好（`ready`），不能在開窗前才等儲存。儲存壞了不能影響開窗與收回。位置交給瀏覽器。
- 測試：`tests/integration/game/pip-panel.test.js`（jsdom，假的 `documentPictureInPicture` 回傳第二個 jsdom 視窗，假的儲存）。**斷言不要拿 jsdom 視窗物件互相比較（`assert.equal(win, other)`）**：失敗時 node 會把整個視窗印出來比對，測試會卡住，改用 `assert.ok(a === b)`。真正的 Chrome 行為（要點擊才能開、置頂、焦點）只能手動驗證。
- 置頂浮窗的「密語」區塊（`whisper-block.js`，`attach(root)` 回傳 `add({ name, text })`；manifest 與 popup 備援注入都要載入，在 `stats-block.js` 之後、`content.js` 之前）：資料不另外解析輸出，由聊天記錄器的 `onIncoming`（`content.js` 的 `onIncomingChat`，先給 `whisperBlock.add` 再 `answerChat`，所以不受自動回覆開關影響）餵進來，只有私聊來訊。開關是 `zapFeatures.whisper`（**缺值＝開**，和其他輔助功能相反；設定頁 `featureWhisper` 靠 `FEATURE_DEFAULT_ON` 區分，`applyZapFeatures` 用 `!== false`），`setEnabled(false)` 清空並停止累積。顏色是 `chrome.storage.local.whisperColor`（`COLORS` 的鍵，缺值＝`orange`，不認得的退回橘；`setColor` 把配色放進區塊的 CSS 變數 `--w-bg`／`--w-accent`／`--w-text`／`--w-name`，閃爍時底色換成亮色、文字換深色 `#1b1200`），設定頁 `whisperColor` 下拉的選項要和 `COLORS` 的鍵一致（測試會比對）。輸出最後一行沒有換行時，`feedChat` 排的 `CHAT_QUIET_MS`（1.5 秒）計時器呼叫記錄器的 `flush` 把它當完整的一行（會讓真的被切開的行在靜止後被當完整行，所以只有靜止夠久才算）；每次收到私聊印 `[catworld] 密語：收到私聊`。累積最近 `MAX`（5）句、新的在最上面，按「清除」才消失；新的一句進來會重播閃爍動畫（`fresh`，先拿掉 class、強制重排再加回）；沒有密語時 `hidden`；和數值區塊一樣用 `:host(:not([data-pip])) .whisper { display: none }` 只在置頂浮窗顯示。文字一律用 `textContent`（遊戲輸出不可信）、壓空白、最多 `MAX_TEXT` 字。`initPanel` 建立要包 try/catch。測試在 `tests/integration/game/whisper-block.test.js`；jsdom 算不出動畫與 `:host` 樣式，閃爍與「主面板看不到」只能手動驗證。
