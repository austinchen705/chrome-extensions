# 隨機表情

- 規格與票在 `.scratch/semote/`（不進 git）。練功觸發開著時偶爾做一組相關的表情（`semote`），只做不帶對象、沒人在旁邊的版本。
- 資料：`docs/data/semotes.tsv`（指令、文字、類別、順序、單獨；使用者在沒人的房間把每個表情不帶對象做一次的真實輸出，作者標類別）由 `tools/gen-emote-data.js` 產生 `catworld-auto-command/emote-data.js`（`CatworldEmoteData`，每列 `[指令, 類別, 順序, 只能單獨]`，**不要手改**；格式不對或少於 100 列時失敗不覆寫）。被略過的 16 個（sleep home hit flee 等，可能是真指令）不收。類別「不用」（太吵、對眾人、低俗、死亡、what wait sorry comfort nothx…）與「要對象」（不帶對象回「X誰？」或沒輸出）永遠不用。`tests/unit/emote-pick.test.js` 比對資料檔與 TSV。
- `emote-pick.js`（純函式，不碰 DOM 與 `chrome.*`；manifest 與 popup 備援注入在 `chat-script.js` 之後、資料檔在它之前，popup.html 也載入它取 `normalizeSettings`）：`pick({ recent, random })` 回 `{ category, commands }`：第一個亂數 < `RARE_CHANCE`（0.05）就從只能單獨出現的（戲劇化、綁場景的 15 個）抽一個；否則依 `WEIGHTS`（累 4、動作 3、思考 3、無奈 2、開心 2、大笑 1、耍寶 1；招呼、加油不用，要有人在旁邊才自然）抽類別，候選＝該類＋`NEAR`（累↔動作、開心↔大笑），思考只可接 `LIGHT_SIGHS`（sigh shrug shake headshake）；第一個從該類抽，耍寶一組一個、其餘 1～3 個，其他的只從順序和第一個相差 `WINDOW`（4）以內的抽，照順序排；`recent`（前兩組）不用，扣完沒有可以當第一個的就不扣。`gapSec` 2～10 整數秒、`macroText` 接成 `a;@等待 N;b`、`normalizeSettings`（`{ enabled, chance }`，只有 true 才開、chance 0～100 否則 5）、`SETTINGS_KEY`＝`emoteSettings`（設定備份的觸發區塊）。
- `content.js`：`doEmote` 用 `startMacro(…, 'emote')` 送一組（不算聊天，不加切換間隔），記 `emoteLast`（STATUS 的 `emote`）與 `emoteRecent`，console 印 `[catworld] 隨機表情：…`；`EMOTE_TRY`（只接受擴充功能自己的頁面）不看機率、間隔、練功組，`emoteBlocked`（驗證碼、真人驗證、因驗證停止）時拒絕。自動：`syncEmote`（`startTriggers`／`stopTriggers`／設定變動時呼叫）在 `emoteWanted`（開關開、練功組 `on`）時暖機 `WARMUP_MS` 再每 `ROLL_MS` `rollEmote`：`Math.random() * 100 < chance`、距上一組（含試做）≥ `MIN_GAP_MS`（只在頁面記憶體）、不在 Idle、巡怪沒在跑、沒被 `emoteBlocked` 擋、練功組引擎的 `statusBlock()`（`trigger-engine.js` 匯出的同一個判斷）沒擋才做；不符合就放棄這次。取消：停止練功組 `cancelMacros('emote')`、`beginCaptcha`、`stopEverything` 與 `retire`（全部巨集）。
- 設定頁：練功分頁（`createTriggerPane` 在 `group.id === 'practice'` 時把 `emoteFold()` 插在開始鈕那一列前面）的 `fold-emote`：`emoteOn`、`emoteChance`（change 時 `normalizeSettings` 存並寫回，**要擋冒泡**，練功分頁的根節點聽 change 會重存整組觸發設定）、`emoteTry`／`emoteMsg`、`emoteLast`（`refreshLive` 照 STATUS）。
- 測試：`tests/unit/emote-pick.test.js`（抽法規則）、`tests/integration/game/emote.test.js`（整個 content script，計時器縮小；試做、取消、自動的暖機、機率、不做的條件、10 分鐘間隔用快的頁面時鐘）、`tests/integration/settings/emote-settings-ui.test.js`。巡怪在跑時不做沒有單獨的測試（要起一整套巡怪）。**對方在場時帶對象做招呼、加油還沒做**：要先有帶對象的輸出樣本。
